\# ML Git Practical



\## Project Title

Machine Learning Project using Git and GitHub



\## Objective

To manage Machine Learning source code using Git and GitHub.



\## Version Control Workflow



1\. Git was installed and configured.

2\. A local Git repository was created.

3\. ML source code was added to the repository.

4\. Changes were staged using git add.

5\. Versions were saved using git commit.

6\. Feature branches were created for development.

7\. Branches were merged into the main branch.

8\. The local repository was connected to GitHub.

9\. Project source code was pushed to GitHub.

10\. Collaboration branches were created.



\## Git Commands Used



\- git init

\- git status

\- git add

\- git commit

\- git log

\- git branch

\- git switch

\- git merge

\- git remote

\- git push

\### Version 1.0

\## Conclusion



Git and GitHub provide version control, source code management,

branching, merging, collaboration, and version history for ML projects.
